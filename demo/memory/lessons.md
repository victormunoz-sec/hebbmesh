# Engineering & Cognitive Lessons — Alex Rivera

- **A-01 `[V]` Idempotent Stripe Webhooks:** Always persist `event.id` in a unique SQLite table before mutating invoice balances; return HTTP 200 immediately on duplicate replay. | sem: double charge fix, payment safety, replay attack, billing integrity
- **A-02 `[V]` WAL Mode for Concurrent Readers:** Enable `PRAGMA journal_mode = WAL` and `busy_timeout = 3000` so live dashboards never trigger `SQLITE_BUSY` during writes. | sem: database lock error, concurrency fix, sqlite busy, locked db
- **A-03 `[V]` Zero-Bloat Structural Indexing:** Extract function and heading signatures before reading 800-line files; `read_file` bloat accounted for 70% of agent input tokens. | sem: save llm tokens, expensive context, file reading cost, ast outline
- **A-04 `[V]` Edge WAF Against Datacenter Scrapers:** Block unverified datacenter ASNs and non-GET methods on public pages at Cloudflare Edge before they ever invoke Workers or D1. | sem: stop web crawlers, bot shield, firewall rules, save d1 reads
- **A-05 `[V]` OPFS SQLite Over IndexedDB:** For offline-first mobile web apps, SQLite compiled to WASM backed by OPFS mirrors server SQL schemas 1:1 and avoids IndexedDB cursor bugs. | sem: browser storage, offline database, mobile sync, pwa cache
- **A-06 `[V]` Proportional Ontological Load:** Never assign multi-archetype persona files to 3B–8B models; restrict SLMs to atomic code/extraction contracts with strict output schemas. | sem: small model crash, local llm loop, prompt size limit, slm stability
- **A-07 `[V]` Same-Model Context Isolation:** A reasoning model polluted with backend logs produces cluttered CSS; spawning a clean UI specialist on the same model fixes layout quality immediately. | sem: bad frontend output, dirty chat history, separate agents, clean slate
- **A-08 `[V]` HMAC Signed Session Cookies:** Replace static admin tokens with `HMAC-SHA256` signed cookies verified via `crypto.timingSafeEqual` and 24-hour TTL expiry. | sem: auth hardening, login security, cookie forgery, timing attack
- **A-09 `[V]` Cache Poisoning Defense on Next.js:** Exclude session cookies, `rsc`, and `next-router-prefetch` headers from CDN cache rules so authenticated pages never leak to anonymous visitors. | sem: cdn leak, stale admin page, cache header bug, cloudflare cache
- **A-10 `[V]` Bounded Pagination on Admin Endpoints:** Never execute unbounded `SELECT *` queries in admin dashboards; enforce `.limit(500)` and cursor pagination to protect serverless memory. | sem: oom crash, slow admin panel, full table scan, row read explosion
- **A-11 `[V]` Zero-Embedding Seeding at Capture:** Have the capturing LLM emit 3–5 synonyms or colloquialisms inline (`| sem:`) so lexical graphs handle metaphors with 0 MB of vector models. | sem: semantic search without embeddings, metaphor matching, synonym bridge, vocabulary mismatch
- **A-12 `[V]` Anti-Super-Hub Episodic Cap:** Partition weekly recaps by functional lobe and cap retrieval at 1 episodic node per query so broad summaries never drown out specific rules. | sem: noisy summaries, graph hub problem, topk crowding, weekly memory
- **A-13 `[V]` Privacy Firewall at Graph Layer:** Exclude private-vault nodes before spreading activation and before A* pathfinding so sensitive data cannot leak even as intermediate hops. | sem: dlp guard, prevent data leak, graph triangulation, secret isolation
- **A-14 `[V]` Anti-Pareidolia A* Bridging:** Require minimum edge weight `>= 0.55` and charge a hub toll on high-degree nodes so shortest-path search refuses to invent fake connections. | sem: false positives graph, hallucinated links, pathfinding penalty, spurious bridge
- **A-15 `[V]` O(1) Incremental Hebbian Writes:** Update only the co-activated neuron counters and edge rows inside a single SQLite transaction instead of rewriting the entire graph file on every query. | sem: fast disk persistence, avoid full rewrite, incremental update, synaptic plasticity
- **A-16 `[V]` Telegraphic Inter-Agent DSL:** Strip polite prose between subagents (`L1<->L2<->L3`) using structured key-value status lines; cuts coordination tokens by 45–60%. | sem: compact agent protocol, cut chatter, machine readable handoff, concise swarm
- **A-17 `[V]` Delegation Cost Threshold:** Only spawn a worker subagent when exploring >3 unknown files or writing >80 lines; tiny 1-file edits are cheaper directly in the specialist. | sem: subagent overhead, when to delegate, swarm economics, micro edit rule
- **A-18 `[V]` Anti-Hallucination Evidence Gate:** Every scout worker report must cite `file:line` and an exact snippet; the specialist spot-checks before merging and terminates the worker. | sem: verify ai output, fake file paths, worker audit, grounded citations
- **A-19 `[V]` Verbal Self-Critique Buffer:** Keep at most 10 active negative rules derived from real mistakes injected at session start; graduate internalized rules weekly to keep prompts lean. | sem: reflexion pattern, stop repeating mistakes, mistake log, lean system prompt
- **A-20 `[V]` Validate Telemetry Before Alerting:** Cross-check database feedback rows against resolved milestone history before waking the founder with false-alarm notifications. | sem: stale alert, false alarm, check history first, noise reduction
- **A-21 `[V]` Prefix-Cache Friendly Prompt Ordering:** Place immutable system rules and tool schemas at the top of the prompt and volatile timestamps at the bottom to maximize LLM provider KV-cache hits. | sem: cheaper api calls, prompt caching, deepseek cache hit, latency drop
- **A-22 `[V]` Graceful Barge-In for Voice UI:** Calibrate microphone echo-cancellation thresholds (~220ms) and immediately cancel in-flight TTS audio streams when the user interrupts mid-sentence. | sem: talk over assistant, voice interruption, audio overlap, live call ux
- **A-23 `[V]` Schema Validation on Public Telemetry:** Enforce strict Zod schemas on anonymous client-side logging endpoints and hard-code low risk levels server-side to prevent SIEM poisoning. | sem: fake logs, log injection, sanitize telemetry, siem security
- **A-24 `[V]` Production Branch Drift Audit:** Verify `production_branch` settings in CI/CD platforms after repo renames; mismatched branch names silently trap commits in preview deployments. | sem: deploy not updating, stuck preview, wrong git branch, cloudflare pages
- **A-25 `[V]` Remove Hardcoded Fallback Secrets:** Fail closed in production when `CRON_SECRET` or `ADMIN_PASSWORD` env vars are missing instead of falling back to development defaults. | sem: default password vulnerability, insecure fallback, env var check, fail closed
- **A-26 `[V]` Measure Pareto Before Optimizing:** Audit 2 weeks of real tool transcripts before building optimization tooling; intuition almost always blames the wrong bottleneck. | sem: profiling first, data driven optimization, find real bottleneck, telemetry audit
- **A-27 `[V]` Atomic File Swaps on Windows:** Write JSON state files to a temporary sibling file and retry `fs.renameSync` with brief backoff to avoid partial reads or AV lock crashes on Windows. | sem: corrupted json, file lock windows, safe write, atomic rename
- **A-28 `[V]` Self-Selling Ad Slots Over Generic Placeholders:** Replace gray "Ad space reserved" boxes with crisp B2B sponsor callouts showing direct copyable email capsules to convert inbound leads. | sem: monetization ui, b2b sponsorship, landing conversion, banner copy
- **A-29 `[V]` Zero-Barrier Free Tier Onboarding:** Avoid demanding tax IDs or corporate registration numbers on free signups; individual contractors act as Trojan horses inside enterprise teams. | sem: plg growth, frictionless signup, user activation, b2b adoption
- **A-30 `[V]` Dual Licensing Strategy (AGPL + Commercial):** Publish core infrastructure under AGPL-3.0 to gain authentic open-source adoption while requiring paid commercial licenses for closed SaaS embedding. | sem: open core business, protect source code, saas copyleft, monetize github
- **A-31 `[V]` Dedicated Localhost Binding for Dev Tools:** Bind local visualization servers strictly to `127.0.0.1` without wildcard CORS headers so browser tabs on external origins cannot read local memory graphs. | sem: localhost security, csrf protection, no cors wildcard, viewer hardening
- **A-32 `[V]` Clean Neutral Benchmarks Beat Personal Anecdotes:** Publish reproducible synthetic datasets and head-to-head baselines (FTS5/BM25) so external researchers can verify claims without private data. | sem: scientific credibility, reproducible eval, public dataset, hacker news proof
- **A-33 `[V]` Separate Core Engine from Turnkey Starter Kits:** Open-source the deterministic memory engine for visibility while packaging turnkey IDE hooks and agent factories as paid starter kits. | sem: gumroad product, monetization funnel, starter template, developer tools
- **A-34 `[V]` Split Monolithic Theses into Focused Papers:** Two crisp 10-page papers (Memory Engine vs. Model Variable & Token Economics) get cited and shared far more than one 80-page manifesto. | sem: research publishing, zenodo doi, technical writing, paper scope
- **A-35 `[V]` Non-Interactive Git Fetch in Automation:** Set `GIT_TERMINAL_PROMPT=0` when running automated repository status checks so expired credentials fail fast instead of hanging background shells forever. | sem: hung git command, credential prompt hang, ci timeout, shell freeze

- **A-38 `[V]` Deterministic Layout Seeding in 3D Graphs:** Derive initial spherical coordinates from deterministic FNV-1a node hashes so reloading a 3D brain viewer preserves spatial muscle memory. | sem: stable 3d positions, deterministic layout, graph sphere, visual consistency
- **A-39 `[V]` Backpressure on Webhook Workers:** Cap concurrent outbound email and webhook retries with exponential backoff to avoid triggering provider rate limits during recovery. | sem: retry storm, queue throttling, email limits, backoff strategy
- **A-40 `[V]` Immutable Audit Trails for Financial State:** Never overwrite historical invoice records in place; append adjustment entries so accounting exports remain reconcilable. | sem: ledger design, accounting safety, append only billing, audit log
- **A-41 `[V]` Zero-Dependency CLI Portability:** Prefer built-in Node.js modules (`node:sqlite`, `node:http`, `node:crypto`) over npm packages to eliminate supply-chain bloat and install friction. | sem: no npm install, supply chain security, pure nodejs, portable cli
- **A-42 `[V]` Anti-Drift Identity Anchors:** Inject a compact 5-line identity and rule anchor at session start so long coding conversations never drift into generic assistant boilerplate. | sem: personality drift, consistent tone, session start hook, system prompt anchor

- **A-44 `[V]` Sub-Millisecond A* Heuristic Weighting:** Scale 3D Euclidean heuristic by `0.05` so A* stays admissible while guiding bridge search naturally across hemisphere boundaries. | sem: graph pathfinding, heuristic tuning, fast shortest path, 3d distance

- **A-47 `[V]` Graceful Fallback from SQLite to Atomic JSON:** Detect `node:sqlite` availability at import time and fall back transparently to atomic JSON swaps on older Node runtimes. | sem: backward compatibility, json fallback, runtime detection, resilient storage
- **A-48 `[V]` Benchmark Ablation Discipline:** Always benchmark the full engine against a feature-ablated version (e.g., without `| sem:`) to prove each component actually earns its complexity. | sem: scientific rigor, ablation study, prove value, feature justification
- **A-49 `[V]` Keyboard-First Canvas Controls:** Provide quick camera reset, pause-orbit, and preset query chips in 3D viewers so first-time visitors experience live firing within 5 seconds. | sem: ux onboarding, interactive demo, quick presets, viewer usability
