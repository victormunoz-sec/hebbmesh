# Zero-Embedding Synaptic Memory & 3D A* Bridging

Instead of bundling 100+ MB ONNX embedding models, Zero-Embedding Seeding (`| sem:`) captures 3–5 synonyms or metaphors at write time as high-weight dendrites (`0.80`). Spreading activation retrieves 5–6 winners in milliseconds, while 3D A* pathfinding uncovers non-obvious bridges under anti-pareidolia hub penalties and strict privacy firewalls.
