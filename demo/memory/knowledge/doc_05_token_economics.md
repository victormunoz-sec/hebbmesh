# Empirical Token Economics & 3-Tier HMAS Orchestration

Measuring real agent transcripts revealed that raw file reading (`read_file`) accounts for 70.1% of input volume. Combining structural outlining (`firmas.mjs`), telegraphic inter-agent messaging (`HMAS-DSL`), quantitative delegation thresholds (`NW-THRESHOLD`), and a bounded verbal self-critique buffer (`Reflexion`) eliminates token waste while isolating specialist contexts. Key concepts evaluated: `HMAS-DSL`, `NW-THRESHOLD`, `TalkHier`, `Reflexion`.
